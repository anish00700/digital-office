Staff

Changes land on each employee's next task — nobody is interrupted mid-job. Desks come from the floor plan, so the office can hold a fixed number of people.

Routines

Audit

Every sensitive read, every request to leave the machine, every redaction and every lockdown, newest first. Kinds only - a value that was redacted is not in this log either.

Safety
